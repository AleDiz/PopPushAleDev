## 🧠 Design Focus & Core Loop

Designed around a **One-Button Arcade Philosophy**:
1. Bounce between microwave walls.
2. Avoid incoming heat hazards.
3. Rhythm-based input timing.
4. Persistent high-score chase.

---

## 🧩 Technical Highlights

Built upon the custom Z80 assembly engine architecture engineered for *Soldier Assemble*.

* **Hardware SRAM Persistence:** Programmed persistent save data writes directly to physical Game Boy cartridge SRAM registers to save high scores permanently across sessions.
